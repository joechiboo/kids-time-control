# Kids Time Control - 兒童數位健康控制系統

一個基於兒童發展心理學的數位健康工具，協助家長建立健康的螢幕使用常規，培養孩子的內在動機與自我管理能力。

> **核心理念**：不用遊戲化獎勵機制，而是透過建立常規、自然後果、培養內在動機和環境設計，幫助孩子建立長期的健康習慣。

## 💡 為什麼不用獎勵機制？

研究顯示，用手機時間當作獎勵會讓孩子將手機視為最高價值的東西，強化「手機等於快樂」的連結，其他活動都變成「為了得到手機」的手段。這會破壞孩子的內在動機，讓他們沒有獎勵就不願意做事。

我們採用更符合兒童發展心理學的方法：

### 🔑 四個核心方法

1. **建立日常常規**
   - 將手機使用視為生活的一部分，而非特別獎勵
   - 設定固定時段和額度，就像刷牙一樣自然
   - 規則保持一致，不因孩子表現好壞而變動

2. **自然後果法**
   - 超時使用就隔天相應減少時間
   - 這不是懲罰，而是讓孩子理解「總額有限」的概念
   - 培養自我管理和時間規劃能力

3. **培養內在動機**
   - 引導孩子自己設定使用時間
   - 討論為什麼需要限制（保護眼睛、還有其他重要活動）
   - 讓孩子參與規則制定，而不是被動接受

4. **環境設計**
   - 全家一起設定「無螢幕時間」
   - 提供豐富的替代活動
   - 父母以身作則，孩子會模仿行為而非聽說教

## 🎯 專案特色

### 核心功能

- **⏰ 智慧時間管理**
  - 每日固定時間額度（基於年齡和專業建議）
  - 使用時才進行倒數計時
  - 每天 00:00 自動重設時間額度
  - 時間用完溫和提醒，非強制鎖定
  - 自然後果機制（超時影響明天額度）

- **📚 教育內容中心**
  - 為什麼需要限制螢幕時間？（兒童友善說明）
  - 數位健康知識（基於 AAP、WHO 指南）
  - 親子對話技巧指南
  - 年齡適宜的使用建議

- **🎨 替代活動建議**
  - 依年齡分類的活動資料庫
  - 戶外活動、創意遊戲、親子互動
  - 可收藏喜歡的活動
  - 家庭活動記錄與回憶

- **📊 正向回饋統計**
  - 使用趨勢圖表（強調進步而非監控）
  - 連續未超時天數記錄
  - 週報/月報（正向語氣）
  - 家庭整體使用概況

- **👨‍👩‍👧‍👦 家庭共同參與**
  - 親子共同制定規則工具
  - 規則討論歷史記錄
  - 家長自我追蹤功能（以身作則）
  - 全家無螢幕時間設定

- **🔧 開發者模式**
  - 隱藏手勢啟動（標題點 2 次 + 健康卡片點 2 次）
  - 測試控制：手動鎖定/解鎖裝置
  - 防止孩童誤觸測試功能

### 技術亮點

- **跨平台支援** - Android (Accessibility Service) / iOS (Screen Time API)
- **即時同步** - WebSocket 實現多裝置即時狀態同步
- **雙端應用** - Vue.js 家長管理端 + Flutter 孩童互動端
- **安全可靠** - 尊重隱私，不追蹤個人內容
- **友善介面** - 溫暖語氣、教育導向的視覺設計

## 🚀 快速開始

### 系統需求
- Node.js 18+
- PostgreSQL 14+
- Redis 6+
- Flutter 3.0+
- Android Studio / Xcode (開發環境)

### 安裝步驟

```bash
# Clone 專案
git clone https://github.com/joechiboo/kids-time-control.git
cd kids-time-control

# 安裝後端依賴
cd backend
npm install
cp .env.example .env  # 設定環境變數
npm run db:migrate     # 執行資料庫遷移
npm run dev           # 啟動開發伺服器

# 安裝前端依賴（家長端）
cd ../frontend-parent
npm install
npm run dev

# 安裝 Flutter App（孩童端）
cd ../mobile-child
flutter pub get
flutter run
```

## 📱 使用場景

### 👨‍👩‍👧‍👦 家長視角
1. **共同制定規則** - 與孩子討論並設定合理的螢幕時間
2. **正向引導** - 查看使用趨勢，給予正向回饋
3. **教育資源** - 學習如何與孩子對話數位健康議題
4. **替代活動** - 規劃家庭活動，提供豐富的替代選項
5. **以身作則** - 追蹤自己的螢幕時間，做孩子的榜樣

### 👦👧 孩童視角
1. **了解時間** - 清楚知道今天還可以用多久
2. **理解原因** - 學習為什麼需要限制螢幕時間
3. **探索活動** - 發現有趣的替代活動
4. **看見進步** - 了解自己的使用習慣和進步
5. **參與決策** - 和家長一起討論規則

## 📚 科學依據

本專案的教育理念基於以下專業建議和研究：

### 權威組織建議

**美國兒科學會（AAP）**
- 2-5 歲：每日螢幕時間不超過 1 小時
- 6 歲以上：家長設定一致的限制
- 強調家庭媒體使用計畫的重要性
- 避免用媒體作為情緒調節或行為獎勵

**世界衛生組織（WHO）**
- 2-4 歲：久坐螢幕時間每日不超過 1 小時
- 強調高品質內容的重要性
- 建議家長陪伴互動
- 重視身體活動和睡眠品質

### 兒童發展心理學原則

1. **內在動機理論**（Self-Determination Theory）
   - 外在獎勵會削弱內在動機
   - 培養自主性比獎懲更有效
   - 理解規則比遵守命令更重要

2. **自然後果教育法**（Natural Consequences）
   - 讓孩子經驗行為的自然結果
   - 不是懲罰，而是學習機會
   - 培養責任感和自我管理能力

3. **環境設計**（Choice Architecture）
   - 改變環境比改變行為更容易
   - 提供替代選項而非單純限制
   - 家長示範比說教更有效

- [AAP Media Plan](https://www.healthychildren.org/English/media/Pages/default.aspx)
- [WHO Guidelines on Physical Activity](https://www.who.int/publications/i/item/9789241550536)
- Deci, E. L., & Ryan, R. M. (2000). Self-determination theory
- Ginsburg, K. R. (2007). The importance of play in promoting healthy child development

## 💬 開發動機

身為工程師父母，我們深知 3C 產品的設計機制和成癮性。與其等孩子成癮後再來補救，不如從一開始就用正確的方式引導孩子建立健康的數位習慣。

這個專案的目標不是「控制」孩子，而是提供工具協助家長：
- 與孩子建立有意義的對話
- 培養孩子的內在動機和自主性
- 全家一起建立健康的數位生活模式
- 以身作則，成為孩子的榜樣
