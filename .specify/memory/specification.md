# 兒童數位健康控制系統 - 產品規格文件

## 1. 專案概述

### 願景
建立一個幫助家長培養孩童健康數位使用習慣的工具，透過**建立常規**和**自然後果**取代獎懲機制，讓孩子學會自主管理時間，而非將手機視為最高價值的獎勵。

### 核心理念
根據兒童發展心理學和數位健康研究，本專案遵循以下原則：

1. **不用獎勵機制**：避免將手機時間當作獎勵，防止孩子將手機視為最高價值
2. **建立日常常規**：手機使用是生活的一部分，就像刷牙一樣自然
3. **自然後果法**：超時使用會影響隔天額度，讓孩子理解「總額有限」
4. **培養內在動機**：引導孩子參與規則制定，理解限制的原因
5. **環境設計**：全家無螢幕時間，父母以身作則

### 目標
- **主要目標**：幫助家長建立孩童健康的數位使用常規
- **教育目標**：培養孩子的自我管理能力和時間觀念
- **家庭目標**：減少親子衝突，增進家庭互動時間
- **健康目標**：遵循專業建議（學齡前兒童每日不超過 2 小時）

### 非目標
- ❌ 不是獎懲系統（無積分、無任務、無獎勵商城）
- ❌ 不是間諜軟體或監控工具
- ❌ 不追蹤孩子的隱私內容
- ❌ 不支援破解或繞過其他 App 的限制
- ❌ 不收集非必要的個人資料

### 與傳統時間控制 App 的差異

| 傳統方式 | 本專案方式 |
|---------|----------|
| 用手機時間當獎勵 | 固定常規，不因表現變動 |
| 積分、任務、商城 | 無遊戲化元素 |
| 懲罰性限制 | 自然後果教育 |
| 家長單方面控制 | 親子共同參與規則制定 |
| 只有限制功能 | 包含使用建議和教育內容 |

## 2. 使用者故事

### 家長視角

#### 故事 1：建立健康常規
**身為關心孩子數位健康的家長**，我希望能夠：
- 設定每日固定的使用時間額度（如平日 60 分鐘、假日 120 分鐘）
- 規則保持一致，不因孩子表現好壞而變動
- 設定全家的「無螢幕時間」（如用餐、睡前）
- 讓孩子參與規則討論和制定過程
- 查看數位健康建議，了解專業推薦標準

#### 故事 2：教育而非懲罰
**身為想要培養孩子自律的家長**，我希望能夠：
- 當孩子超時使用時，系統自動調整隔天額度（自然後果）
- 提供為什麼需要限制的教育內容（保護眼睛、培養多元興趣）
- 看到孩子的使用趨勢，作為親子對話的基礎
- 提供替代活動建議，而非只是「不能用」
- 以身作則模式：記錄家長自己的使用時間

#### 故事 3：家庭共同成長
**身為重視家庭時間的家長**，我希望能夠：
- 設定全家無螢幕時段，大家一起遵守
- 追蹤家庭整體的螢幕使用時間
- 規劃親子共讀、戶外活動的時間
- 記錄家庭活動照片和美好時光
- 定期與孩子檢視使用狀況，調整規則

### 孩童視角

#### 故事 4：清楚的規則與額度
**身為小學生**，我希望能夠：
- 清楚看到今天的使用額度和剩餘時間
- 知道使用規則是固定的，不會突然改變
- 了解為什麼需要限制使用時間
- 收到友善的時間提醒（不是嚴厲的警告）
- 參與家庭規則的討論

#### 故事 5：理解自然後果
**身為學習自我管理的孩子**，我希望能夠：
- 看到我的使用歷史和趨勢
- 理解「今天用太多，明天就會少一點」的概念
- 學會規劃自己的使用時間（要先做作業還是先玩）
- 看到自己的進步（如連續一週沒有超時）
- 有機會和爸媽討論調整規則

## 3. 功能需求

### 3.1 時間管理核心功能

#### 固定額度制度
- **每日基本額度**：
  - 學齡前（3-5歲）：建議 30-60 分鐘
  - 學齡（6-12歲）：建議 60-120 分鐘
  - 青少年（13+）：建議 120-180 分鐘
  - 家長可自訂額度

- **額度規則**：
  - 平日/假日可設定不同額度
  - 額度每日 00:00 自動重設
  - 未使用的額度**不可累積**（避免囤積行為）
  - 只在使用時才倒數計時

- **自然後果機制**：
  - 今日超時 X 分鐘 → 明日額度減少 X 分鐘
  - 今日完全不使用 → 明日額度不變（避免囤積誘因）
  - 連續 7 天未超時 → 家長可獲得建議增加 15 分鐘作為「信任成長」
  - 超時記錄可視化，讓孩子理解自己的使用模式

#### 時段管理
- **無螢幕時段**：
  - 用餐時間
  - 睡眠時間（含睡前 1 小時緩衝）
  - 家庭活動時間
  - 作業/學習時間

- **彈性時段**：
  - 緊急聯絡（電話、簡訊）永遠可用
  - 教育類 App 可設定為不計時
  - 親子視訊通話不計時

#### 裝置控制
- **自動鎖定**：
  - 額度用完時自動鎖定
  - 進入無螢幕時段時自動鎖定
  - 鎖定時顯示友善訊息和替代活動建議

- **手動解鎖**：
  - 僅家長可解鎖
  - 需註明解鎖原因（作為對話記錄）
  - 額外使用時間會從隔天扣除（自然後果）

### 3.2 教育與引導功能

#### 數位健康教育
- **為什麼需要限制？**
  - 保護視力發展
  - 確保充足睡眠
  - 培養多元興趣
  - 增進家庭互動
  - 提升專注力

- **專業建議來源**：
  - 美國兒科學會（AAP）建議
  - 世界衛生組織（WHO）指南
  - 台灣衛福部建議
  - 眼科醫師專業意見

#### 替代活動建議
當時間用完或接近時，系統提供：
- **戶外活動**：公園、運動、散步
- **家庭遊戲**：桌遊、拼圖、角色扮演
- **創意活動**：繪畫、手工、音樂
- **閱讀時間**：繪本、故事書
- **幫助家務**：簡單的家事參與

### 3.3 家庭參與功能

#### 規則共同制定
- **親子對話工具**：
  - 提供討論引導問題
  - 記錄規則制定的討論內容
  - 設定「規則試行期」（如 2 週後重新檢討）
  - 孩子可提出調整建議

- **規則視覺化**：
  - 用孩子能理解的方式呈現規則
  - 圖示化時間表
  - 互動式規劃工具

#### 家庭無螢幕時間
- **全家共同遵守**：
  - 家長和孩子的使用時間都被記錄
  - 「家長也在玩手機」時會提示
  - 共同設定家庭活動時間
  - 記錄家庭共處時光

- **家庭活動規劃**：
  - 提供活動點子
  - 記錄活動照片和心得
  - 追蹤家庭互動時間

### 3.4 數據與洞察

#### 使用統計（教育目的）
- **趨勢呈現**：
  - 每日/週/月使用時間
  - 超時次數統計
  - 自制力進步曲線
  - 與建議標準的對比

- **親子對話基礎**：
  - 「我們一起來看看這週的使用情況」
  - 不是監控，而是學習工具
  - 孩子可以看到自己的所有數據
  - 數據不會被用來懲罰

#### 洞察報告
- **每週家長報告**：
  - 孩子本週的使用模式
  - 進步的地方（正向回饋）
  - 可以討論的地方
  - 專業建議

- **每月成長報告**：
  - 長期趨勢分析
  - 自律能力成長
  - 家庭互動時間增加
  - 下個月目標建議

### 3.5 家長身教工具

#### 家長使用追蹤
- 記錄家長自己的螢幕時間
- 在孩子面前使用時會提示
- 家長超時同樣會被記錄
- 全家一起成長的理念

#### 正向榜樣功能
- 家長設定自己的使用限制
- 和孩子一起遵守無螢幕時間
- 記錄親子共讀、運動時間
- 強調「一起變更好」而非「大人管小孩」

### 4.2 核心資料模型

```typescript
// 家庭成員
interface FamilyMember {
  id: string
  familyId: string
  name: string
  role: 'parent' | 'child'
  ageGroup: 'preschool' | 'school' | 'teen'
  avatarUrl?: string
}

// 時間規則（簡化版，不含積分）
interface TimeRule {
  id: string
  childId: string

  // 固定額度
  dailyQuota: {
    weekday: number  // 分鐘
    weekend: number
  }

  // 無螢幕時段
  blockedPeriods: Array<{
    name: string  // "用餐時間"、"睡眠時間"
    startTime: string  // "07:00"
    endTime: string    // "08:00"
    days: number[]     // [1,2,3,4,5] = 週一到週五
  }>

  // 自然後果設定
  consequences: {
    enabled: boolean
    overtimeCarryover: boolean  // 超時扣明天額度
  }

  // 規則制定記錄
  agreements: Array<{
    date: Date
    discussionNotes: string
    agreedBy: string[]  // 參與討論的成員 ID
    reviewDate: Date    // 預計檢討日期
  }>
}

// 使用記錄（簡化版）
interface UsageSession {
  id: string
  childId: string
  deviceId: string
  startTime: Date
  endTime?: Date
  duration: number  // 秒
  quotaUsed: number  // 使用的額度（分鐘）
  isOvertime: boolean
}

// 每日使用摘要
interface DailyUsage {
  id: string
  childId: string
  date: Date
  quotaAllocated: number  // 分配的額度
  quotaUsed: number       // 實際使用
  overtime: number        // 超時分鐘數
  carryoverPenalty: number // 扣除明天的額度
  notes: string           // 當日記錄
}

// 替代活動建議
interface AlternativeActivity {
  id: string
  category: 'outdoor' | 'family' | 'creative' | 'reading' | 'chores'
  title: string
  description: string
  ageGroup: string[]
  duration: number  // 建議時長（分鐘）
  imageUrl: string
}

// 教育內容
interface EducationContent {
  id: string
  type: 'why_limit' | 'health_tip' | 'family_activity' | 'discussion_guide'
  title: string
  content: string
  targetAudience: 'parent' | 'child' | 'both'
  ageGroup?: string
  source: string  // 資料來源（AAP、WHO等）
}

// 家庭活動記錄
interface FamilyActivity {
  id: string
  familyId: string
  type: 'no_screen_time' | 'outdoor' | 'reading' | 'game' | 'other'
  title: string
  date: Date
  duration: number
  participants: string[]  // 成員 ID
  photos: string[]
  notes: string
}
```

# 報告
GET    /api/reports/weekly/:childId
GET    /api/reports/monthly/:childId

# WebSocket 事件

ws: session-started     # 開始使用

ws: family-activity     # 家庭活動開始

## 8. 技術挑戰與解決方案

### 8.1 Android 實作挑戰

**挑戰：Accessibility Service 權限**
- 問題：用戶可能拒絕授權或不懂如何設定
- 解決：
  - 清楚的圖文引導
  - 說明為什麼需要此權限
  - 提供影片教學

**挑戰：不同 Android 版本行為差異**
- 問題：碎片化問題
- 解決：
  - 優先支援主流版本（Android 8+）
  - 充分測試常見裝置
  - 提供裝置相容性列表

### 8.2 iOS 實作挑戰

**挑戰：Screen Time API 限制**
- 問題：功能受限，需要額外設定
- 解決：
  - 提供詳細設定指南
  - 說明功能限制
  - 考慮未來使用 MDM 方案

### 8.3 教育內容品質

**挑戰：確保內容準確性**
- 解決：
  - 引用權威來源（AAP、WHO、眼科醫師）
  - 標註資料來源
  - 定期更新內容
  - 諮詢兒童發展專家

**挑戰：內容本地化**
- 解決：
  - 參考台灣衛福部建議
  - 考慮文化差異
  - 使用台灣家庭熟悉的案例

  - 學齡前兒童每日不超過 2 小時

  - 睡前 1 小時避免使用
